# tough-reply：帮你回一条难回的消息

同事甩活、领导一句「你看着办」、被人阴阳了一句……这些消息不难打字，难的是怎么回才不得罪人，又不委屈自己。

tough-reply 是一个 AI Skill。把对方的原话或聊天截图发给 AI，它会：

1. **先读懂对方**：TA 真正想要什么、是什么情绪、是不是在阴阳你
2. **补齐背景**：先看背景卡；如果你的 AI 工具接上了办公 IM、日程、项目工具，它会自己去翻相关的聊天、任务进度和日程；还缺的才问你，一次最多 3 个
3. **写出几版回复**：温和版、边界版、给方案版，都是不撕破脸的；被阴阳、被甩锅时再加一版「体面回击」
4. **自查后再给你**：不编事实，不替你答应截止时间和加班，去掉 AI 腔，回复里不会混进「需要我再改改吗」
5. **只写草稿**：发送永远由你自己点

## 能帮你回什么

| 场景 | 例子 |
|---|---|
| 拒绝被甩活 | 「你做表最快了，帮我汇总一下呗」 |
| 催进度 | 跨部门同事已读不回 |
| 领导随口一句 | 「你看着办」「在吗」「这个怎么样了」 |
| 被阴阳、被冒犯 | 「这么拼，准备当主管了？」「你太敏感了」 |
| 推不掉的临时加活 | 「客户又改了，今天弄一下」 |
| 被甩锅 | 「这个不是你在跟吗？」 |
| 自己出错要道歉 | 报价单填错了 |
| 下班、假期消息 | 晚上十点「PPT 你再改改」 |
| 客户、甲方 | 「加个功能吧，应该挺简单的」 |
| 群里被点名 | 领导在群里 @ 你问数据 |
| 开口求人 | 找别的部门要数据 |

## 效果示例

> 你：同事说「哟，又加班啊，这么拼，准备当主管了？」当着好几个人。我这周就是事多，不想吵
>
> AI：
>
> 📌 对方的意思：表面夸你，实际在说你出风头（情绪：阴阳）
> 💡 建议：当众别解释，轻轻带过；想出口气用 ④
>
> ① 温和版
> 哪有，这周要交的东西多，赶一赶。你们先走吧
>
> ② 边界版
> 这周事多而已，跟当不当主管没关系
>
> ③ 给方案版
> 这周项目收尾，忙完就正常了。你那边要是也赶，可以一起点个外卖
>
> ④ 体面回击 · 顺着接
> 借你吉言。真当上了第一个请你吃饭
>
> ✅ 发之前确认：
> - ④ 发出去后对方可能接着调侃，想好要不要继续接

## 怎么用

装好后直接说就行，比如：

- 「帮我回一下：<对方原话>」
- 发一张聊天截图：「这条怎么回」
- 「领导说『你看着办』，我该怎么接」
- 「同事又阴阳我了，想怼回去，要体面一点」

不满意可以接着说：「再短点」「再硬一点」「第二版换个说法」。

## 背景卡：说一次，以后都记得

常打交道的人（领导、某个同事、某个客户），第一次聊完 AI 会问你要不要存成背景卡。存下来以后，下次提到这个人就不用再交代关系。

还可以存一张「我的说话习惯」：贴 5～10 条你平时发的工作消息，AI 会学你的称呼、口头禅和标点，写出来更像你本人打的字。

卡片默认存在你工作目录的 `people/` 文件夹里，模板在 [`templates/`](templates/)。工具不能写文件时，AI 会把卡片发给你，你自己保存，下次贴回去。

## 隐私

- 自动拉上下文时只读不写，只翻和这条消息相关的记录，并告诉你读了什么

- 发给 AI 之前，建议把真名、公司名、项目名、金额换成代号
- 公司规定不能外传的聊天内容，不要发给公司没批准的 AI 工具
- 背景卡只用代号，存在你自己的电脑上。`.gitignore` 已经排除了 `people/`，不会被误提交

## 它不会做的事

- 不替你发消息
- 不编事实、不帮你撒谎
- 不写骂人、人身攻击的话。体面回击的底线是「对方挑不出错」
- 遇到骚扰、违法要求、劳动权益问题，它会建议你留证据、找 HR 或专业人士，而不是帮你圆过去
