# 体面回击

被阴阳、被冒犯、被甩锅时，用户除了「不撕破脸」，也常想出口气。体面回击要做到：对方听得懂你不好惹，但挑不出你一个字的错。

## 什么时候出回击版

- 对方在阴阳、带刺、冒犯，或者在甩锅
- 用户说了「想怼回去」「来点爽的」「不想忍」
- 不出：对方是善意但说话笨；对方是你的直属上级且你没表示要回击（这时只在 💡 里提一句可以怎么回击，不出成稿）

## 四种风格

### 1. 顺着接

不接对方话里的刺，只接表面的客气，把对方架在那里。

- 公式：把对方的话当成真心夸你 → 大方收下 → 顺手回敬一句客气话
- 例：对方「这么拼啊，又加班？」→ 是啊，这周要交的多。你也早点走
- 适合：对方习惯阴阳，你不想纠缠
- 效果：对方一拳打在棉花上

### 2. 装傻反问

假装没听懂潜台词，请对方把话说明白。阴阳的人最怕被要求把话挑明。

- 公式：「啊？」「是吗？」+ 按字面理解的反问
- 例：对方「拿奖了，运气真好」→ 啊？我还以为是那三个通宵起作用了
- 例：对方「你太敏感了吧」→ 是吗？那你刚才那句是什么意思，我可能真理解错了
- 适合：对方当众说你，需要让旁人看清是谁在找事
- 注意：反问只问一次，问完就停，不要追着吵

### 3. 温柔立边界

语气平和，但把底线说出来。对方再继续就是 TA 不讲理。

- 公式：平和的事实 + 一句明确的边界
- 例：对方「你这么厉害，以后多罩着我们」→ 互相帮忙应该的，不过我手上的活也排满了，各自加油
- 例：对方「开个玩笑嘛」→ 我知道你是开玩笑，不过这种玩笑我不太喜欢，下次别开了
- 适合：已经越界、反复发生、需要一次说清
- 效果：最稳，不会被说「你怎么这么凶」

### 4. 幽默带过

用一句轻松的话把场面结束，显得你根本没往心里去。

- 公式：自嘲或夸张 + 转移话题或结束话题
- 例：对方「又买新衣服，工资很高嘛」→ 工资不高，但心情得自己哄
- 适合：小场合、对方是半熟的同事、气氛不想搞僵
- 注意：幽默要用户本人说得出口。用户的说话习惯偏严肃，就别选这种

## 怎么挑

| 情况 | 首选 | 备选 |
|---|---|---|
| 私聊里阴阳 | 顺着接 | 幽默带过 |
| 当众阴阳 | 装傻反问 | 温柔立边界 |
| 反复越界 | 温柔立边界 | 装傻反问 |
| 对方是上级 | 温柔立边界（语气再软一档） | 顺着接 |
| 甩锅 | 温柔立边界 + 摆事实（见 `scenarios/blame.md`） | 装傻反问 |

## 红线

- 不骂人，不用脏字和谐音脏字
- 不碰对方的外貌、性别、年龄、地域、家庭、学历
- 不翻对方的旧账和私事
- 不在回击里编事实
- 不建议用户截图挂人、在群里公开对质，除非是「被甩锅」需要摆证据的情况
- 回击发出去之后对方可能升级，在 ✅ 里提醒用户：准备好对方接下来可能说什么
