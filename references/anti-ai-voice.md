# 去掉 AI 腔

AI 写的回复一眼就能认出来，发出去比回得慢更尴尬。有人把 AI 回复连着结尾那句「需要我改成更简洁的版本吗？」一起发给了领导，领导回了句「不需要了」。

写完每一版，都过一遍下面的清单。

## 一定要删的

| 类型 | 例子 | 改成 |
|---|---|---|
| 写给用户的话混进了回复 | 「需要我再改简洁一点吗？」「（可根据实际情况调整）」「希望对你有帮助」 | 删掉。这些话只能出现在回复正文之外 |
| 客服腔开头 | 「非常理解您的心情」「首先感谢您的信任」「您好，关于您提到的问题」 | 直接说事，或用一句口语接住：「理解，这个确实急」 |
| 公文腔 | 「鉴于目前的工作安排」「为确保交付质量」「烦请知悉」 | 「我这周排满了」「怕赶出来质量不行」 |
| 过度道歉 | 「真的非常抱歉」「实在不好意思给您添麻烦了」，一条里道歉两次以上 | 最多一次「不好意思」，拒绝不合理请求时不道歉 |
| 过度感谢 | 「感谢您的理解与支持！」 | 删，或换成「谢啦」「辛苦」 |
| 套话结尾 | 「期待您的回复」「如有任何问题随时联系我」「祝工作顺利」 | 私聊里删掉。邮件可保留一句 |
| 油腻语气词堆叠 | 「好的呢～」「没问题哒」「宝」「亲」「呀～」连用 | 按用户的说话习惯来；没有习惯参考时，一条最多一个语气词 |
| 排比和对仗 | 「既能……又能……还能……」「不仅……而且……」 | 只留一个要点 |
| 列点 | 私聊回复里用「1. 2. 3.」或「首先、其次、最后」 | 改成一两句话；真有三件事，就分成几条短消息 |
| 书面标点 | 分号、破折号、书名号滥用，引号包着关键词 | 用逗号和句号，或者不加标点 |
| 每句都完整工整 | 主谓宾齐全、没有一个口语词 | 允许省略主语：「今天弄不完了，明早给你」 |

## 像人打字的默认规则

用户没给说话习惯时，按这些写：

- 句子短。一句话能说完就不分两句。
- 可以省主语：「收到，下午看」比「我收到了，我会在下午查看」自然。
- 对上级：不用「哈」「哒」「呢」，不用表情；可以用「好的」「收到」「明白」。
- 对平级熟人：可以带一个语气词（「哈」「啦」），可以用一个常见表情。
- 对客户：礼貌但不卑微，不用网络流行语。
- 数字和时间写具体：「周四下班前」比「尽快」好。
- 少用「您」还是「你」，看对方平时怎么叫用户。拿不准时，对上级和客户用「您」，对平级用「你」。

## 用了说话习惯的话

用户有 `people/我.md` 或贴过自己的消息时：

- 优先照着用户的称呼、口头禅、标点、表情写
- 用户平时不说的话，就算礼貌，也不要写
- 用户平时说话很冲，回复可以保留一点直接，但仍然守住「对方挑不出错」

## 最后检查

把每一版读一遍，问自己：用户本人在手机上会这样打字吗？不会就改。
