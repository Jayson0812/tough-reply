# 不撕破脸的回复结构

## 通用三段：接住 → 立场 → 台阶

几乎所有难回的消息都能套这个结构。和「三明治拒绝法」是一个思路，区别在第三段：不只是给个理由，而是给对方一条能走的路。

1. **接住**：先回应对方这句话本身，让对方知道你看到了、听懂了。一句就够。
2. **立场**：说清楚你能做什么、不能做什么。这是整条回复的核心，不能含糊。
3. **台阶**：给对方一个下一步：替代方案、新的时间、更合适的人、你能做的那一小部分。

例子（同事让你帮忙做对方的周报数据）：

> 接住：这个数据是挺费时间的
> 立场：我今天手上两个要交的，实在腾不出手
> 台阶：表格模板我发你，按这个填会快很多

合起来：这个数据是挺费时间的，我今天手上两个要交的，实在腾不出手。表格模板我发你，按这个填会快很多

## 三版的区别

三版用同一套事实，只是把力气放在不同段上：

| 版本 | 力气放在哪 | 适合 |
|---|---|---|
| 温和版 | 接住写得最暖，立场说清楚但口气软 | 关系重要、对方是好意、你以后还要求 TA |
| 边界版 | 立场最直接，台阶最短，不留「下次可以」的口子 | 对方反复来、已经越界、你需要一次说清 |
| 给方案版 | 台阶写得最具体，把事情往前推 | 你不想只说「不」，想把问题解决掉 |

三版写完对照看一下：如果只是换了几个词，说明没写出差别，重写。

## 每一段的写法

### 接住

- 回应对方的处境或情绪：「这个确实急」「理解，客户那边催得紧」
- 回应对方的信任：「谢谢想到我」（只在对方真的是在信任你时用，别每次都用）
- 直接确认收到：「收到」「看到了」
- 不要：「我非常理解你的感受」「首先感谢你的信任」，太像客服

### 立场

- 说事实，不说情绪：「我今天要交 A 和 B」比「我真的太忙了」更有力
- 理由给一个就够。理由越多越像找借口，也越容易被对方逐条反驳
- 不用「可能」「也许」「尽量」去软化拒绝。要拒绝就说「做不了」「接不了」
- 不要过度道歉。拒绝合理请求以外的事，不需要说「真的很抱歉」

### 台阶

可以给的台阶：

- 时间：「明天上午可以帮你看一眼」（只在用户确实愿意时给）
- 一部分：「整理我来不及，但我可以把去年的模板发你」
- 别人：「这块 B 更熟，你可以问问 TA」
- 流程：「这个要走一下需求单，我这边排期才能进来」
- 选项：「A 和 B 我只能先做一个，您看先做哪个？」（对上级最好用）

不要给用户做不到的台阶。用户没说愿意，就不要写「下次一定帮你」。

## 几种常用的变形

| 情况 | 结构 |
|---|---|
| 对上级说「做不完」 | 接住 → 列出手上的事 → 请对方排优先级 |
| 催别人 | 接住对方的忙 → 说清你卡在哪、影响什么 → 给一个具体时间点 |
| 认错 | 认事实 → 说已经做的补救 → 说以后怎么防 |
| 回应批评 | 接住（不辩解）→ 说明事实（有出入时）→ 说接下来怎么做 |
| 求人 | 说清要什么 → 说清对方要花多少力气 → 给对方好处或感谢 |

## 长度

- 私聊：一条 15～60 字最常见。超过 80 字就考虑分两条发，或者删掉一段。
- 接住只用半句到一句，立场最晚放在第二句。不要把「不」藏在最后。
- 对上级：结论放第一句，接住可以省掉。
