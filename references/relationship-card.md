# 背景卡

AI 回消息最累的地方，是每次都要重新交代「我是谁、对方是谁、我们什么关系」。背景卡就是把这些写一次，以后反复用。

背景卡有两种：

- **对方卡**：每个常打交道的人一张，存为 `people/<代号>.md`
- **我的说话习惯**：只有一张，存为 `people/我.md`

模板在 `templates/背景卡.md` 和 `templates/我的说话习惯.md`。

## 对方卡写什么

| 项 | 例子 | 为什么要 |
|---|---|---|
| 代号 | 产品 A、王姐、甲方 C | 不写真名也能用 |
| 和我的关系 | 直属领导 / 平级跨部门 / 下属 / 客户 | 决定语气和能不能拒绝 |
| 熟悉程度 | 很熟，私下会聊天 / 只在工作群说过话 | 决定能不能开玩笑 |
| 对方的说话风格 | 说话很直 / 爱用反问 / 喜欢先夸再派活 | 帮你读懂潜台词 |
| 对方在意什么 | 结果和时间 / 面子 / 流程合规 | 回复要先回应这个 |
| 过往经历 | 上次帮过一次后，每周都来找 / 曾经在会上甩锅 | 判断这次是不是老套路 |
| 我的底线 | 不帮做对方的本职工作 / 周末不处理非紧急的事 | 写回复时守住 |
| 平时怎么称呼 | 张总 / 王姐 / 直接叫名字 | 回复里直接用 |

不用每项都填。填了「关系」和「熟悉程度」就能用，其他的以后慢慢补。

## 什么时候建卡

- 第一次为某个人写回复，写完问用户：「要不要把 TA 存成背景卡？下次就不用再说一遍。」
- 用户同意：能写文件就按模板写进 `people/<代号>.md`，把这次对话里得到的信息填进去，没提到的项留空；不能写文件就把填好的卡片整段输出，告诉用户下次贴回来。
- 用户以后补充了新信息（比如「TA 上次又在会上甩锅」），问一句要不要更新卡片。

## 怎么用卡

- 用户提到某个代号，或者消息里能对上某张卡的人，先读卡。
- 卡里的信息和用户这次说的不一致，以这次为准，并问要不要更新卡。
- 卡里的「底线」写进策略，回复不能越过它。

## 我的说话习惯写什么

让回复像用户本人打的字，而不是 AI 写的：

- 称呼习惯：叫领导「X 总」还是「X 哥」，叫同事名字还是昵称
- 句子长短：一句话说完，还是喜欢分几条发
- 标点习惯：爱用句号吗？用不用感叹号、波浪号
- 表情：常用哪几个表情，对领导用不用
- 口头禅：「好嘞」「OK」「收到哈」「没问题」
- 不说的话：比如「亲」「宝」「哈喽」

最好的办法是让用户贴 5～10 条自己平时发的工作消息，你从里面总结。总结完给用户看一眼再存。

## 隐私

- 卡片里只用代号，不写真名、手机号、公司名。
- 卡片存在用户自己的电脑上，不要建议用户上传到任何地方。
