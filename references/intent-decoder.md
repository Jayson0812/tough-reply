# 读懂对方

回错消息，多半不是字没写好，而是没看懂对方要什么。动笔前先回答四个问题：

1. **字面**：TA 说了什么
2. **潜台词**：TA 其实想要什么（一个结果、一个态度、一个台阶、一个人背锅）
3. **情绪**：着急、不满、试探、客气、阴阳、中性
4. **TA 希望你怎么接**：给方案、给时间、表态、闭嘴、认错

## 看信号，不只看字

| 信号 | 常见含义 |
|---|---|
| 平时带表情，这次没有 | 情绪变了，大概率不满或着急 |
| 单独一个「。」或「好。」 | 对上级或熟人来说，常常是不满 |
| 「嗯」「哦」「行」 | 可能是知道了，也可能是不想聊；看前一句是谁说的 |
| 称呼变了（从「哥」变成「张经理」） | 关系在拉远，或者要公事公办、留记录 |
| 下班时间、周末发 | 要么真急，要么 TA 习惯这样；看 TA 平时是不是也这样 |
| 在群里问而不是私聊 | 要的是公开表态，或者想让别人看见 |
| 抄送了别人、拉了领导 | 在留痕、施压，回复要更严谨 |
| 连发好几条 | 着急，回复要先给结论 |
| 隔了很久才回一个字 | 不想继续，或者在忙，不要追问情绪 |
| 用「咱们」「我们」 | 想拉近，常常接着要请你帮忙 |
| 先夸你再说事 | 后面大概率是要你多干活 |

## 常见原话速查

| 原话 | 可能的意思 | 怎么接 |
|---|---|---|
| 你看着办 | ① 真放权 ② 要你先给方案 ③ TA 不满意但懒得说 | 给一个具体方案让 TA 选，不要只回「好的」 |
| 不着急，你看着弄 | 客气。多数时候是有时间要求的 | 主动报一个时间：「我周四下班前给你」 |
| 有空吗 / 在吗 | 有事要找你，可能是加活 | 回「在的，您说」，先听事再答应，不要先说「有空」 |
| 这个怎么样了 | 在催，或者上面在问 TA | 先给结论（到哪了、什么时候好），再说细节 |
| 再想想 / 再看看 | 不满意，或者不想直接拒绝你 | 问清楚卡在哪：「是方向还是细节？我按您的意见改」 |
| 辛苦了 | 结束对话，或者客套 | 简单收住，不用长篇感谢 |
| 好的呢 / 好哒 | 可能是真客气，也可能是敷衍 | 看前文。要落实的事，补一句确认时间 |
| 你比较熟，你来吧 | 想把活推给你 | 按「拒绝被甩活」处理 |
| 这个很简单吧 | 压低你的工作量，常接着压时间或压价 | 说清楚实际要做哪几步，不接「简单」这个定性 |
| 顺便帮我…… | 小忙，但可能越来越多 | 判断是真顺手，还是要你另花时间 |
| 我也是听上面说的 | TA 不想担责 | 问清楚是谁要、要什么，必要时去源头确认 |
| 你怎么看？ | 可能真问意见，也可能在试探你的站队 | 说事实和建议，不评价人 |
| 你太敏感了 / 开个玩笑嘛 | TA 说了冒犯的话，现在想让你闭嘴 | 按「被阴阳」处理 |
| 这么拼啊 / 准备当主管了？ | 带刺的夸 | 按「被阴阳」处理 |
| 之前不是说好了吗 | 在追责，或者记忆有出入 | 先对事实：「我记得当时是……，您看是不是这样」 |
| 都可以 / 随便 | 真随便，或者希望你先提两个选项 | 给两个具体选项让 TA 挑 |
| 收到 | 知道了，不代表同意 | 要 TA 同意的事，单独问一句 |

## 怎么判断是不是在阴阳你

同时出现越多条，越可能是阴阳：

- 夸的内容和场合不搭（你加班，TA 夸你「真有空」）
- 用反问或感叹：「这么快就弄完了？」「你可真行」
- 当着别人说
- 带「哟」「啧」「呵呵」「哈哈」但内容并不好笑
- TA 平时就爱这样说别人

拿不准的时候，默认按善意理解回第一句，同时把边界放进去。这样就算 TA 真是善意，你也没失礼。

## 输出时怎么写

在 📌 里只写一句话，比如：

- 对方的意思：想让你先出一个方案，TA 再拍板（情绪：中性偏着急）
- 对方的意思：表面夸你，实际在说你出风头（情绪：阴阳，八成把握）
- 对方的意思：拿不准。可能是真问你进度，也可能是上面在催 TA
